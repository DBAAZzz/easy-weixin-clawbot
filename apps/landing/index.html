easy-weixin-clawbot

多账号微信 AI Agent 管理平台

一个后台，统一管理多个微信 AI 账号。账号、记忆、工具、技能、静态资源、 RSS 订阅、任务中心和 Webhook 全都在里面，还能用 MCP Server 继续扩。

核心能力

八种能力，围着同一个内核转

  • 账号管理

    多个微信 AI 账号统一接入，不用一个个开窗口盯着。

  • 记忆

    为每个账号配置独立的长期记忆，对话上下文不串台。

  • 工具

    给 Agent 挂载可调用的工具，能力按需组装。

  • 技能

    把工具和提示词打包成可复用的技能，跨账号共享。

  • 静态资源

    图片、文件等素材集中托管，回复里直接引用。

  • RSS 订阅

    订阅源更新自动推进会话，做资讯播报很顺手。

  • 任务中心

    定时任务与异步任务统一调度，执行状态可查。

  • Webhook & MCP

    对外用 Webhook 集成，对内用 MCP Server 接协议扩展。
